# Azur Lane Community Tier List

An interactive, ECTL-style endgame PvE tier list and searchable Azur Lane ship wiki.

## Features

- Community tier list with ship portraits and content-specific ratings
- Wiki directory covering 896 ships, searchable and filterable by name, class, faction, hull type, and rarity
- Stable detail pages for every ship with level 125 stats, English and Vietnamese skill descriptions, community notes, and recommended REGAL equipment sets for each available scenario
- Static, dependency-free site that works directly on GitHub Pages

The site is generated from community-maintained Azur Lane data and is intended for reference only. It is unofficial and is not affiliated with Manjuu, Yongshi, or Yostar.

## Sources

- [REGAL](https://azur-lane-regal.suchiguma.com/) for community ratings, notes, and equipment recommendations
- [Azur Lane Wiki](https://azurlane.koumakan.jp/) and current game data for ship information and level 125 statistics
- [iujab/azurlane-images](https://github.com/iujab/azurlane-images) for remotely loaded ship portraits

## GitHub Pages

The published site is the root `index.html`. In repository settings, configure Pages to deploy from the `main` branch and `/ (root)`.
